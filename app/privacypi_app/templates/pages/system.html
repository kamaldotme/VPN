Restart and reset

These interrupt the internet for everyone connected to PrivacyPi. You will be asked to confirm.

Restart the dashboard Only this web page restarts (a few seconds). WiFi and internet keep working. Try this if the dashboard acts strangely.
Restart PrivacyPi Turns the whole device off and on again. It starts in about 1 minute, then WiFi is gone for about another minute. Your settings are kept.
Shut down Switches PrivacyPi off safely. Do this before unplugging it for a long time. To start it again, unplug the power and plug it back in.
Factory reset Erases everything — settings, passwords, VPN accounts — and starts first-time setup again. This cannot be undone. Make a backup first.
