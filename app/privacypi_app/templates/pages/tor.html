Bridges — only if Tor will not connect

Some internet providers and countries block Tor. A bridge is a private entrance that gets around the block. If Tor works for you, leave this empty.

To get bridges, visit bridges.torproject.org (opens in a new tab), copy the lines it gives you and paste them below — one per line. Supported kinds: obfs4 and snowflake.

Checking saved bridges…

Saved bridges are not shown here again. Saving replaces the whole list and reloads Tor, which can interrupt Tor browsing for a few seconds.

Hide website lookups with Tor

Every time a device opens a website it first looks up the site's address. Turning this on sends those lookups through Tor, so no lookup service sees them. The trade-off: pages start loading a little more slowly. It works in any mode, not only Tor.

Changing this restarts ad blocking, so websites may not load for a few seconds.
