Why this exists

A LAN router can't get a public TLS certificate (no public domain), so PrivacyPi runs its own tiny certificate authority. After you install the root cert below on each of your devices, every visit to https://{{ host_mdns }} or https://{{ host_ip }} becomes a trusted, green-padlock connection. No browser warnings, ever.

2. Install it

macOS
  1. Double-click privacypi-root.crt — Keychain Access opens.
  2. Choose System keychain (not "login"), enter your admin password.
  3. Find Caddy Local Authority, double-click it.
  4. Expand Trust → set "When using this certificate" to Always Trust.
  5. Close — confirm with Touch ID / password. Done.
iOS / iPadOS
  1. Open this page in Safari and tap the download link — accept "Allow" on the profile prompt.
  2. Settings → General → VPN & Device Management → tap Caddy Local Authority → Install.
  3. Settings → General → About → Certificate Trust Settings → toggle Caddy Local Authority to ON.
Android
  1. Save the file to your device.
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Pick privacypi-root.crt. Confirm.
  4. Note: Chrome on Android only trusts user-installed CAs for system-level apps; some apps still warn. Firefox uses its own store and ignores OS CAs entirely.
Windows
  1. Right-click privacypi-root.crt → Install Certificate.
  2. Store location: Local Machine (admin needed) → Place all certificates in: Trusted Root Certification Authorities.
  3. Finish. Restart any open browser.
Linux (Debian / Ubuntu) 
sudo cp privacypi-root.crt /usr/local/share/ca-certificates/privacypi-root.crt
sudo update-ca-certificates
# For Firefox: about:preferences#privacy → Certificates → Import
Firefox (any OS)
  1. Firefox uses its own trust store (independent of the OS).
  2. about:preferences#privacy → scroll to Certificates → View Certificates… → Authorities tab → Import.
  3. Pick privacypi-root.crt, check Trust this CA to identify websites, OK.
