Do I need this?

No — this is optional. The dashboard works fine at http://{{ lan_gw }} while you are on PrivacyPi's own WiFi.

If you prefer a secure https:// address with a padlock, your browser first has to be told to trust this PrivacyPi. You do that once per phone or computer by installing a small "certificate" file — a kind of ID card that PrivacyPi made for itself. PrivacyPi uses it only for this dashboard. Install it only on your own devices, and only from your own PrivacyPi.

Step 2 — Install it on your device

Tap your type of device for instructions. The certificate is listed as Caddy Local Authority.

iPhone / iPad
  1. Open this page in Safari and tap Download certificate. Tap Allow when asked.
  2. Open Settings → General → VPN & Device Management → tap Caddy Local Authority → Install.
  3. Open Settings → General → About → Certificate Trust Settings and switch Caddy Local Authority on.
Android
  1. Tap Download certificate to save the file.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate. (On some phones, search Settings for "certificate".)
  3. Choose privacypi-root.crt and confirm.
  4. Good to know: Chrome will now trust the dashboard. Firefox and some other apps ignore certificates you install yourself and may still warn.
Mac
  1. Double-click privacypi-root.crt. The Keychain Access app opens.
  2. Choose the System keychain (not "login") and enter your Mac password.
  3. Find Caddy Local Authority in the list and double-click it.
  4. Open Trust and set When using this certificate to Always Trust.
  5. Close the window and confirm with Touch ID or your password.
Windows
  1. Right-click privacypi-root.crt and choose Install Certificate.
  2. Choose Local Machine, then Place all certificates in the following store → Trusted Root Certification Authorities.
  3. Click Finish, then close and reopen your browser.
Firefox (on any computer)
  1. Firefox keeps its own list of trusted certificates, so it needs this extra step.
  2. Open Firefox Settings → Privacy & Security → scroll to Certificates → View Certificates → Authorities → Import.
  3. Choose privacypi-root.crt, tick Trust this CA to identify websites, then OK.
Linux (Debian / Ubuntu)

Run these two commands in a terminal, in the folder where you saved the file:

sudo cp privacypi-root.crt /usr/local/share/ca-certificates/privacypi-root.crt
sudo update-ca-certificates

If you use Firefox, also follow the Firefox steps above.

Step 3 — Check that it worked

Open one of these addresses. You should see a padlock and no warning. If you still get a warning, close and reopen the browser and try again.

https://{{ host_mdns }}/
https://{{ host_ip }}/

Emergency recovery words

PrivacyPi locks the secrets you save (such as proxy passwords) with a secret key kept on its memory card. These 24 words are a paper copy of that key. If the memory card ever fails, the words are the only way to unlock those saved secrets again.

Write the words on paper and keep the paper somewhere safe. Do not take a screenshot or photo, and never type them into a website or message. Anyone who has these words can unlock your saved secrets. The words disappear from the screen after 60 seconds.
