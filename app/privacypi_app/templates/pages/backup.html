Make a backup

A backup is one file that you download and keep somewhere safe (your computer, a USB stick). If your PrivacyPi breaks or you reset it, you can use the file to get everything back.

What is inside the file:

  • All PrivacyPi settings, including your VPN and proxy details
  • The dashboard's data: your devices, history and your dashboard login
  • Your Tor settings
  • Your ad-blocking (DNS) settings
The file is locked with your dashboard password. It is encrypted, so nobody can read it without the password you type below. The password is not stored in the file and cannot be recovered — if you forget it, the backup is useless. Write it down somewhere safe.

Restore from a backup

Puts the settings from a backup file back onto this PrivacyPi.

This replaces all current settings with the ones in the backup file, and cannot be undone. The dashboard, Tor and ad-blocking restart, so the internet may pause for up to a minute.

It must be the same password the dashboard had when the backup was made. If you have changed your password since then, first change it back on the System page, then restore.
