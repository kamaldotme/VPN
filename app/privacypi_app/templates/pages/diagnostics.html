Connection checks

Type a website and pick a check. The check is run from PrivacyPi itself, so it tells you whether PrivacyPi can reach the internet.

Can it be reached?Sends a few test signals and waits for an answer (ping).
Can the name be found?Looks up the website's internet address (DNS lookup).
Which route does it take?Lists the stops between PrivacyPi and the website (traceroute). Takes up to 15 seconds.
Pick a check above to start.

Speed test

    

      Measures how fast the internet is through PrivacyPi right now, with your current privacy mode.
      A VPN or Tor is normally slower than a direct connection. Takes about 30 seconds and uses some data.
