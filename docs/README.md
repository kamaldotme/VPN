# PrivacyPi documentation

Documentation for PrivacyPi 2.6.0. The project overview is in the [main README](../README.md);
the current state and open items are in [STATUS.md](../STATUS.md).

## For users

| Document | Read it when |
|---|---|
| [USER-GUIDE.md](USER-GUIDE.md) | You want to set PrivacyPi up and use it: flashing, the setup wizard, the dashboard, VPN, Tor, backup, factory reset. |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | Something does not work: no setup WiFi, no internet, VPN will not connect, forgotten password. |
| [FAQ.md](FAQ.md) | You want to know what it protects against, what it logs, which hardware works, how fast it is. |

## For developers and contributors

| Document | Read it when |
|---|---|
| [DEVELOPER.md](DEVELOPER.md) | You want to understand or change the code: architecture, boot sequence, building the image, the development loop, tests, pitfalls. |
| [CONTRIBUTING.md](../CONTRIBUTING.md) | You want to report a bug, share a hardware test or send a pull request. |
| [SECURITY.md](../SECURITY.md) | You found a security problem and want to report it privately. |

## Historical material

These folders are kept as a record. They describe an **older, Ubuntu-based version** and do not
match the current code. Do not use them as instructions.

| Folder | Content |
|---|---|
| [history/](history/) | Session hand-off notes and the tracker from the May 2026 build. |
| [superpowers/](superpowers/) | The original specification and implementation plans. |
| [ops/](ops/) | Runbook and optional-hardening notes for the old installer. |
| [screenshots/](screenshots/) | Dashboard screenshots from earlier versions. The current pages look different. |
