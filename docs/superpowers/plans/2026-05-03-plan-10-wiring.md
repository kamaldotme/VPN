# PrivacyPi — Plan 10: Wiring & Integration

**Goal:** Make every "overview" page from Plan 9 fully functional. End state: VPN credentials enterable in UI; .ovpn upload works; Tor bridges editable; DNS profile switchable; password change + factory reset wired.

---

## Tasks

1. **VPN credential form** — POST username/password per provider, write to `/etc/privacypi/vpn/<p>/auth.txt` via privileged helper script (added to sudoers whitelist)
2. **.ovpn file upload** — multipart POST, save to `/etc/privacypi/vpn/<p>/servers/`, populate dropdown
3. **Server selector** — populate `current.ovpn` symlink to selected server, used by openvpn@privacypi.service
4. **Tor bridge editor** — textarea POST → write torrc snippet, reload tor
5. **DNS profile switcher** — POST profile name, update Setting + AdGuard config via API
6. **Change password** — current + new + confirm, bcrypt, audit
7. **Reboot Pi** — confirm dialog → reboot via privileged helper
8. **Factory reset** — confirm dialog → wipe DB, /etc/privacypi/vpn/*, /etc/tor bridge edits → run wizard again
9. **Verification** — drive each form via Python requests
