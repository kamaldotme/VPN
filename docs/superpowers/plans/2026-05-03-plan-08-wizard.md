# PrivacyPi — Plan 8: First-Boot Setup Wizard

**Goal:** Build a captive-portal style setup wizard that runs **before** the main UI on a fresh PrivacyPi. End state: SD card → first boot → user connects to PrivacyPi WiFi → browser auto-opens wizard → completes setup → wizard locks itself away.

**Architecture:**
```
First boot detection: settings table has setup_complete=false
                  ↓
   Flask before_request: redirect everything → /setup
                  ↓
Wizard pages: 1. Welcome 2. Set admin pw + TOTP scan 3. Profile pick
              4. First VPN (skip OK) 5. Done
                  ↓
Set setup_complete=true → wizard routes 404 from now on
```

The captive-portal redirect is a **Flask before_request hook** that intercepts everything and routes to `/setup/*` until done.

---

## Tasks

1. Add `setup_complete` setting (default False)
2. Add `before_request` hook: if not complete and url not in `/setup`, redirect
3. Wizard blueprint: 5 pages with progressive form data saved to session
4. On final step: hash password, save TOTP, write profile preset, mark complete
5. Profile presets:
   - **Just Privacy** — VPN slot active, AdGuard Standard
   - **Maximum Privacy** — Tor mode armed, AdGuard Strict, leak guards on
   - **Family** — AdGuard Family preset (adult block on), schedule UI
   - **Power User** — no preset, defaults
   - **Travel** — anti-DPI on (Plan 6), proxy ready, kill switch by default
6. Verification: end-to-end via Python requests
